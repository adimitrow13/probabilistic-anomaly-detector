# Прототипен софтуерен инструмент за вероятностно откриване на аномалии върху публични набори от данни

* **Автор:** Алекс Димитров

---

## Описание на проекта

Настоящият проект представлява софтуерна система за интерактивен анализ и автоматизирано откриване на аномалии (outliers) в таблични набори от данни. Системата се основава на вероятностни подходи, които моделират функцията на плътност на нормалното поведение и идентифицират наблюдения с екстремно ниска вероятност като потенциални отклонения.

Инструментът предоставя графичен потребителски интерфейс (Web UI), визуализация на вероятностните плътности и контури, гъвкаво управление на праговете за чувствителност ($\alpha$-quantile), както и сравнителен анализ на ефективността чрез количествени метрики.

---

## Основни функционалности

* **Поддържани алгоритми:**
  * **Gaussian Mixture Model (GMM):** Параметричен/полупараметричен модел за мултимодални разпределения чрез Expectation-Maximization (EM) алгоритъм.
  * **Kernel Density Estimation (KDE):** Непараметрична оценка на плътността на вероятността чрез Гаусово ядро.
  * **Isolation Forest:** Базов еталонен модел, основан на изолиране чрез случайни дървета на решения.
* **Интерактивен интерфейс:**
  * Зареждане на публични бенчмаркове (ODDS) или качване на произволен потребителски CSV файл.
  * Филтриране, нормализация на признаците и проекция в 2D пространство чрез редукция на размерността (PCA).
  * Интерактивно настройване на прага за аномалност ($\alpha$).
  * Графична визуализация на точките, логаритмичното правдоподобие (log-likelihood) и изолинии на плътността.
* **Оценка на точността (при наличен етикет / Ground Truth):**
  * Изчисляване на матрица на объркване (*Confusion Matrix*).
  * Статистически метрики: *Precision*, *Recall*, *F1-Score*, *ROC-AUC*, *PR-AUC*.
* **Експорт:** Възможност за експортиране на идентифицираните аномалии в CSV формат.

## Архитектура на проекта

Системата следва принципите на чистата архитектура (Clean / Layered Architecture) и разделение на отговорностите:

```text
probabilistic-anomaly-detector/
├── data/                  # Данни (raw и processed)
├── src/                   # Бизнес логика и алгоритмично ядро
│   ├── models/            # Имплементация на алгоритмите (Strategy Pattern)
│   ├── data_loader.py     # Модул за зареждане и валидация на данни
│   ├── preprocessor.py    # Скалиране и редукция на размерността (PCA)
│   ├── threshold.py       # Логика за динамично изчисляване на прагове
│   ├── evaluation.py      # Модул за метрики и валидация
│   └── visualizer.py      # Генератор на интерактивни визуализации
├── ui/                    # Потребителски уеб интерфейс (Streamlit)
├── tests/                 # Модулни тестове (Pytest)
├── Dockerfile             # Контейнеризация на приложението
├── docker-compose.yml     # Оркестрация и мапинг на портове
├── requirements.txt       # Дефиниция на зависимостите
└── README.md              # Документация на проекта
```

## Инсталация и стартиране

### Вариант 1: Локално стартиране с виртуална среда (Препоръчително за разработка)

1. **Клониране на хранилището:**
   ```bash
   git clone https://github.com/adimitrow13/probabilistic-anomaly-detector.git
   cd probabilistic-anomaly-detector
   ```

2. **Създаване и активиране на виртуална среда:**
   ```bash
   # За macOS/Linux:
   python3 -m venv .venv
   source .venv/bin/activate

   # За Windows:
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. **Инсталиране на зависимостите:**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Стартиране на уеб приложението:**
   ```bash
   streamlit run ui/app.py
   ```
   Приложението ще се отвори автоматично на адрес `http://localhost:8501`.

---

### Вариант 2: Стартиране чрез Docker (Препоръчително за защита и внедряване)

1. **Изграждане на контейнера:**
   ```bash
   docker compose build
   ```

2. **Стартиране на контейнера:**
   ```bash
   docker compose up
   ```

3. Отворете браузър на адрес: `http://localhost:8501`.
